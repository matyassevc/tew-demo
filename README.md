# Window Showcase

Build a modern, multi-page website demo for TOP EURO WINDOWS (tew.cz) — a Czech manufacturer of wooden euro windows, doors, and gates based in Kostelec u Kyjova. This is a redesign demo; use the original Czech texts exactly as provided below. Replace all images with clean placeholder blocks (solid light gray 
#F0F0EC with a subtle centered label like "[ foto ]").

Design direction

Reference aesthetic: clean, serious, industrial-craft feel similar to tubotech.cz — not flashy, not generic agency template. Think: precision manufacturing company that takes pride in quality.

Background: off-white / warm white 
#F8F8F5 for page body
Primary color: deep charcoal / almost-black 
#1A1B1E for headings, nav, footer
Accent: one muted warm tone — forest green 
#3D5A47 or dark slate 
#2C3E50 — pick whichever reads better. Use sparingly: CTA buttons, active nav, hover states only
Typography: modern geometric sans-serif only — Inter or Plus Jakarta Sans. No serif. Bold (700–800) for headings, regular (400) for body. Large, confident type scale.
No AI slop — no stock-looking illustrations, no gradient blobs, no decorative icons everywhere. Clean whitespace, strong grid, real content only.
Responsive — mobile-first, looks good on phone and desktop
